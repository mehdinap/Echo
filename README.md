# اکو (Echo)

اکو یک اپ اندروید برای **پخش موسیقی** و **چت کردن** است.

- با **Jetpack Compose** ساخته شده
- بک‌اندش با **Node.js** است
- از معماری **Clean + MVI** استفاده می‌کند
- دو حالت **روشن** و **تاریک** دارد
- از **فارسی و انگلیسی** پشتیبانی می‌کند

## اجرا
### بک‌اند
```bash
cd backend
npm install
npm run seed
npm start
```

## امکانات
- پخش موسیقی
- دانلود آهنگ برای کاربران ویژه
- جستجو
- پلی‌لیست
- چت آنلاین
- نمایش وضعیت پیام‌ها
- حالت آفلاین برای چت
- تنظیمات زبان و تم
